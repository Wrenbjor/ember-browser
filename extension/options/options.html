◆ Ember Browser Agent

Settings for the side-panel assistant (Mode 2) and the MCP bridge (Mode 1).

Local LLM (chat mode)

How many actions the model may take before being forced to answer. Raise for long unsupervised automations.
Used for sliding-window trimming on long tasks. Match your server's configured context length (e.g. Ollama's OLLAMA_CONTEXT_LENGTH) — not the model's theoretical maximum.

MCP bridge (Mode 1)

Must match the port the local mcp-server runs on (default 8765). Change requires restarting both.
